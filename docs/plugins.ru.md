# Плагины NewCatroid (.nplug)

Плагины позволяют кастомизировать основной интерфейс приложения и его поведение. Плагин распространяется в виде файла `.nplug`.

> Другие языки: [English](plugins.en.md) • [Português (pt-BR)](plugins.pt-BR.md)

## Что такое файл .nplug?

Файл `.nplug` — это **ZIP-архив** с обязательным манифестом `plugin.json` в корне:

```json
{
  "packageName": "com.example.myplugin",
  "name": "My Plugin",
  "version": "1.0",
  "description": "Что делает мой плагин"
}
```

- `packageName` — уникальный id плагина. Установка плагина с уже существующим `packageName` будет отклонена.
- `name`, `version`, `description` — показываются в списке плагинов.

### Необязательные части архива

- `src/` — Java-исходники плагина. Главный класс должен называться `plugin.Main` и реализовывать интерфейс `PluginEntry` (`void onLoad(Context context)`). Исходники компилируются **на устройстве** (ECJ + D8) в `plugin.dex` при следующем запуске приложения.
- `settings.json` — JSON **массив** настроек для экрана конфигурации плагина. Ключи: `key`, `type`, `title`, `defaultValue`, `summary`, `entries`, `entryValues`, `min`, `max`, `action`, `toast`, `storage`. Поддерживаемые типы: `boolean`, `string`, `list`, `slider`, `button`.

## Установка плагина

1. Откройте **Настройки → Плагины**.
2. Выдайте разрешение **«Поверх других приложений»** (нужно для функций оверлея).
3. Нажмите **Импорт плагина** и выберите файл `.nplug`.
4. **Перезапустите приложение** — плагины загружаются при старте.

## Что умеет плагин

- Подписываться на события приложения через шину событий: `"Activity.onShow"`, `"Activity.onHide"`, `"Settings.onButtonAction"` (обработчики — функции LunoScript).
- Показывать оверлеи поверх текущей активности (`PluginOverlayManager`).
- Предоставлять экран конфигурации через `settings.json`.

### Безопасный режим

Если включена настройка `force_safe_mode`, плагины не загружаются вообще.

## Где хранятся плагины

Установленные плагины лежат в `<внутренняя память приложения>/plugins/<packageName>/`.
