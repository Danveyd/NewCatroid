# Библиотеки NewCatroid (.newlib)

Библиотека позволяет создавать собственные **блоки** и **формулы** для проектов NewCatroid на языке [LunoScript](https://github.com/Danveyd/LunoScript). Библиотеки распространяются в виде файлов `.newlib`.

> Другие языки: [English](libraries.en.md) • [Português (pt-BR)](libraries.pt-BR.md)

## Что такое файл .newlib?

Файл `.newlib` — это **ZIP-архив**, содержащий до трёх записей:

| Запись | Содержимое | Обязательно |
|---|---|---|
| `code.txt` | Исходный код LunoScript с определениями `fun` | да |
| `formulas.xml` | Определения кастомных формул | нет |
| `bricks.xml` | Определения кастомных блоков | нет |

### code.txt

Обычный LunoScript. Каждая формула и каждый блок ссылаются на функцию, определённую здесь. Стандартный шаблон редактора выглядит так:

```lunoscript
fun sum(a, b) {
    return Number(a) + Number(b);
}

fun toast(sprite, text) {
    MakeToast("Text is: " + String(text));
}
```

Встроенные функции LunoScript, такие как `Number()` и `MakeToast()`, доступны «из коробки».

### formulas.xml

```xml
<formulas>
  <formula id="my_formula" function="sum" displayName="Sum">
    <params>
      <param type="NUMBER" default="0"/>
    </params>
  </formula>
</formulas>
```

- `id` — уникальный идентификатор.
- `function` — имя `fun` из `code.txt`.
- `displayName` — имя, которое показывается в редакторе формул.
- Каждый `<param>` имеет `type` (`NUMBER`, `STRING`, `USER_VARIABLE`, `USER_LIST`) и `default` (значение по умолчанию в редакторе).

### bricks.xml

```xml
<bricks>
  <brick id="my_brick" function="toast" header="Show {0}">
    <params>
      <param type="TEXT_FIELD" name="text"/>
    </params>
  </brick>
</bricks>
```

- `id` — уникальный идентификатор.
- `function` — имя `fun` из `code.txt`.
- `header` — текст, который отображается на блоке; для параметров используйте плейсхолдеры `{0}`, `{1}`, ...
- Каждый `<param>` имеет `type` (сейчас поддерживается только `TEXT_FIELD`) и `name` (внутреннее имя, передаваемое в функцию LunoScript).

## Использование библиотеки в проекте

1. Откройте проект и перейдите в раздел **файлы → Библиотеки**.
2. Скопируйте / выберите файл `.newlib` в папку `libs` проекта.
3. Библиотека загрузится автоматически.
4. Ваши кастомные блоки появятся в категории **Библиотеки** на палитре блоков.
5. Ваши кастомные формулы появятся в редакторе формул под заголовком **Библиотеки**.

Изнутри: каждая библиотека выполняется в собственном интерпретаторе LunoScript, а в качестве id библиотеки используется имя файла (вместе с расширением `.newlib`).

## Создание библиотеки

Используйте встроенный редактор библиотек (пункт меню **Создать библиотеку** в списке проектов). В нём три вкладки: **Код**, **Формулы** и **Блоки**.

- **Код** — редактор LunoScript с подсветкой синтаксиса и проверкой синтаксиса на лету.
- **Формулы** — добавление формул (уникальный id, отображаемое имя, имя функции из кода, параметры с типом и значением по умолчанию). Все поля обязательны, функция должна существовать в `code.txt` (`fun <имя>`).
- **Блоки** — добавление блоков (уникальный id, текст заголовка вида `Show {0}`, имя функции из кода, параметры с типом и внутренним именем). Блоки поддерживают до 8 параметров.

Кнопка **Экспорт** сохраняет текущую библиотеку в файл `.newlib`, **Импорт** — загружает её, **Очистить** — сбрасывает сессию редактора.

> Примечание: редактор библиотек автоматически сохраняет сессию локально (`last_session.json`), но это сохранение используется только редактором — в экспортированный архив `.newlib` попадают только `code.txt`, `formulas.xml` и `bricks.xml`.

## Где хранятся библиотеки

- Библиотеки проекта: `<внутренняя память приложения>/<имя проекта>/libs/`
- Автосохранение редактора: `<внутренняя память приложения>/library_drafts/last_session.json`
